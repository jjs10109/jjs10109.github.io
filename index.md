## RepoIQ
**Codebase Visualization Platform · Team Project · In Progress**

RepoIQ is a collaborative web application designed to help developers explore unfamiliar GitHub repositories and understand relationships within a codebase.

I contribute to the React front end using JSX and CSS. My current Sprint 2 tasks focus on repository listing, repository details, and add/remove functionality, including backend integration and testing.
