## JPM Implied Volatility Lab
**Option Pricing · Machine Learning · Python**

A quantitative research project exploring the implied-volatility
structure of JPM equity options.

The pipeline derives implied volatility from option quotes using
Cox–Ross–Rubinstein and Black–Scholes–Merton pricing models, then
compares Linear Regression, Random Forest, and XGBoost using
chronological evaluation.

A Streamlit dashboard provides interactive views of volatility
smiles, model errors, and data coverage. A synthetic sample
dataset supports reproducible offline demonstrations.

**Technologies:** Python, pandas, NumPy, SciPy, scikit-learn,
XGBoost, Streamlit, Plotly.

**Current status:** Research prototype with incomplete historical
data coverage. Further validation is in progress.

[View code and methodology](https://github.com/jjs10109/Chooser-Option-Pricing)
